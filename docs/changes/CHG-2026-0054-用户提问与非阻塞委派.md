## 4. 真实提问接口与调用身份

### 中立接口

- ToolInvocationContext包含 `turn_id: Option<String>`、`response_index: usize`、`tool_call_id: String`，由Engine真实调用路径提供；不得从模型参数或最近同名tool_start猜测。上下文中不含Bearer、Office地址、浏览器展示身份或授权标志。
- ToolExecutor增加默认兼容的 `call_with_context` 入口；默认调用原call。Context／Goal／问答等实际经过的包装必须保留身份。ToolCallOutcome、Message及StopReason现有公共结构不新增字段／变体。
- 使用Engine可信控制接口处理“允许结束／以新事实接续／受控暂停”，由Host注入，仅本回合有效，默认None。工具正文、structured JSON、After hook和Office动作不能伪造该控制。
- 中立问题类型放Core，状态与协调放Engine；使用既有serde依赖，不给Engine偷偷增加未声明依赖，不把Office类型下沉。

### 模型工具契约

拟采用 `request_user_input` 为真实问答入口，每次一个非空 `question`，`options`为2–8个包含稳定 `id` 与 `label` 的选项，可选简短说明；自定义回答能力始终开启。普通选项身份不能占用既有协议的custom保留标识，所有字段走严格校验。

回答只允许“选一个普通选项”或“自定义文字1–1000字符”，不能混合。成功工具结果包含逻辑question_id、实际发起者与对应原调用、回答来源及明确选项／自定义内容。未提交默认项不是答案，普通回答不批准计划或授予工具权限。

Host不继续向模型宣传会立即成功的旧clarify为真实等待；如保留clarify兼容别名，必须落到同一真实问答处理器及校验。未装配交互运行时的默认CLI保持既有行为，不声称本轮完成终端交互产品。

问题归属主会话、发起会话、执行回合及原调用；子问题显示到主会话并标识真实发起者。主会话共享FIFO，与审批投递协调但结果与权限互相独立；不同主会话独立处理，不能按工作目录混为一队。

## 5. 执行、等待、暂停与收尾

### 子执行控制

拟采用 `start_agent`、`get_agent_status`、`wait_agent` 三个入口，复用原任务、名称、真实task_id及可选goal_task_id参数；状态／等待使用明确的child session及execution turn身份。最终机器字段随实际实现核对并登记在本CHG，不增加HTTP路由。

启动在真实受理和登记后返回运行／排队状态，不携带尚未产生的最终结果；查询和等待必须校验父关系、目录、可见来源及当前执行许可，不启动新回合。等待有上限，超时只返回真实状态，不取消子任务或补充预算。旧delegate_task通过同一runtime等待真实终态，保留旧结果格式与来源兼容。

子并发owned permit由真实执行持有至终态和清理。排队与父等待不能占有使孩子无法进展的模型／工作区资源。事件变化唤醒原父执行，没有新事实时不额外模型空转；真实结果可靠进入父历史并去重，不能通知线程抢父session锁并发改写。

### 受控暂停

问题轮到展示时才确定原五分钟deadline；排队不扣时长。无有效答案时，可信控制在当前工具批次已结算、调用／结果配对保存后暂停分支，不继续下一次依赖模型请求，不靠返回普通Err文字约束模型。

TurnExecution区分受控暂停与真正失败／取消：暂停保留已结算消息、真实工具事实及已用预算，以免明确继续时重复已完成副作用；异常和取消仍保持原恢复保护。公开回合五态保持原版，逻辑问题／子执行的paused另行记录，不能因为外层回合结束就误判Goal为已产出。用户必须明确继续，人工暂停及已有授权规则继续有效。

### 父子收尾

正常结束前仍有关联运行、排队或期限内待答子工作，则原执行进行事件等待；新事实安全接入后再进行必要汇总。全部结果处理或剩余工作明确暂停后，才如实结束。此为本项目前台执行适配，不称作Codex统一强制wait-all规则。

原预算、显式停止、异常、shutdown和真正取消优先；不通过新回合、等价任务或重投获得新许可。停止关闭本次问题及相关父子执行，其他主会话不受影响。Goal绑定仍按真实任务／计划版本／尝试验证，启动不计完成，真实产出与验收分开，过期结果不推进计划。

## 6. 记录、恢复与兼容

选用Host私有版本记录 `user_question_v1` 与 `child_execution_v1`，经现有SessionEvent::Unknown、runtime唯一writer及journal事务追加。Core中立值与这些私有事件的存储包装分开；不新增Store枚举、API、独立数据库或writer。

问题记录包括逻辑身份、主／发起会话、原turn／user message／response／tool call、问题及选项、queued／waiting／answered／expired／cancelled／interrupted状态、展示generation及ID、首次轮到展示时确定的原deadline、可靠答案或结束原因。子执行记录包含父／子及确切回合、原来源、真实状态与结果交付边界；结果正文仍来自已保存子回合及父真实交付记录，不复制整段子历史。

有效答案必须保存后再唤醒原调用，保存失败不宣称成功。重启发生在答案已保存但普通tool_result未写入的间隙时，孤儿恢复先核对可靠接受事实，不能覆盖成unknown后重问或重跑。去重针对同逻辑问题及真实执行，不宣称跨网络／进程的通用恰好一次保证。

单活动页面刷新或切换时，沿既有office.read核对展示丢失，排除原请求已结束／正在接受后，撤销旧POST，以新display ID投递同逻辑问题原剩余时间。不能复用已seen的展示ID，不能无条件轮换清空草稿。剩余不足1000ms直接到期，不向上延长。

已接受并保存的答案不重问；原响应丢失而后台未确认时，只能在原剩余期限重问，不猜答案。AI Office没有已答结果回查接口，不承诺找回未知答案、未提交草稿或所有标签页同步恢复。

Goal／既有聊天观察断流只在真实待答的有界期间允许恢复；显式stop始终有效，断开或重连不能重建执行许可。重启后未完成执行与待答标中断，不恢复future或自动重投；由用户明确继续，已保存答案及结果作为已知事实使用。

回退／分支按可见来源user message及确切执行身份重建事实；不复制旧许可或可回答旧展示。上下文压缩只改变模型视图，原件及验收事实保留，沿已有授权原件读取；父只取得有权使用的子状态／结果，不能读取其他主会话或整段子历史。
