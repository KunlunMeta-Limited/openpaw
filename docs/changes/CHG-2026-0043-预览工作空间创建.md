## 接口和边界

API-HOST-OFFICE-WORKSPACE-001：POST /api/pawoffice/workspaces，沿用全部 Host 路由的 Basic 鉴权，JSON 仅含 name。成功 201 返回原 officeSnapshotSchema 快照。非法名称 400；同名/已存在目录 409；办公室达到100时 422；持久化故障500。错误 JSON 为 {error:string}。

名称去首尾空白后为1–40 UTF-16字符，不允许控制字符、路径分隔符、Windows非法字符、点路径、尾点及设备名。只能在规范化的 Host config.workspace 下新建一层目录，不能复用已有目录或跟随已有符号链接。admission 串行创建，register 仍用现有 records 锁和原子持久化。注册失败仅移除本次刚建立的空目录，不删除既有目录。成功不创建 Session、不调用模型，不改变审批。

main 复用现有表单；收到快照后进入现有 office.sync 处理，随后由既有 Host 五秒同步发布至 gateway。人物点击恢复原场景菜单，左侧员工继续 employee.inspect。

替代方案：只加不可用按钮不能满足此次用户选择；只加浏览器示例房间不能产生真实工作目录；不新增服务、依赖或独立目录数据库。
