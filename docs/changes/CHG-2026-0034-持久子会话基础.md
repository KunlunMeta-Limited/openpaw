## 接口与数据流

普通 session JSONL 追加前向兼容 session_child_v1 关系记录（parentID、child ID、显示名和旧展示 workspace ID）；不创建第二套会话存储。统一 SessionHandle、accept_turn、Engine turn_execution 和 Store finish transaction 保存子任务输入、工具和答复；公开 GET/session、message 与全局 SSE 均使用真实子 ID。父 delegate_task 和汇总仍在父历史，返回文本和 structured 字段同时给父模型真实 task_id。保留旧 task/name 和 feature workspaceId/parentSessionId，不按近义名称或相同任务读取答案缓存。

新子只接任务文字和必要系统说明，无父历史、附件、桌面或递归委派。复用 WorkspaceToolHost 工作区写锁和全局模型请求额度。父等待子时继承父调度授权，不再申请第二个整体回合 permit；模型 limiter 仅包一次。子审批仍独立，父停止/断连/超时取消本轮子与其审批；详情读取无执行副作用。

## 替代方案

拒绝继续创建临时 Session 或只缓存最终答案：不能提供真实公共历史。拒绝在 Host 再造 AgentLoop/journal：违反 ADR-003。拒绝子使用父工具包装：会继承桌面身份与递归委派。暂不实施明确 ID 续办、完整分页/刷新、容量策略、失败尝试持久化、重启迁移，它们属于后续票。
