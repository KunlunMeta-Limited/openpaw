## 2. 变更原因

用户在Office确认生成报告或命令时，必须执行确认的最终输入；拒绝不产生副作用，停止后命令孙进程必须结束。当前Hook晚于审批、并行遗漏校验/metadata、bash不接受外层授权、子进程树与Windows管道、隔离降级、Todo并发均违反此需求。修复D05—D11及同一出口的D34；全量门禁新发现D35（现有TLS传递依赖安全补丁），不提前实现Office菜单/路由或Host资源协调。

T1前置已核实：用户本轮明确审核通过；GitHub PR #5已合入，T2基线ac1b58285fb6c73dce6363ce88fe62100199bb73，T1最终head 383d0922eba3d069794015e1f280668a690c482c。实际使用merge commit，不虚构squash或独立GitHub reviewer。T1 push CI通过；PR事件的另一轮CI因GitHub账单/额度未启动，历史失败保留，不称通过。T2必须重新取得当前版本双平台证据。

## 6. API 变化

保留ToolExecutor::call/call_cancellable和旧ApprovalRequest::new；新增有默认实现的call_with_context、调用标识/最终输入精确绑定、可等待真正执行观察入口。旧执行器可以继续实现原方法；新增ApprovalRequest可选绑定字段会影响外部直接struct literal调用方，必须明确。核心不引Office/OpenCode DTO。Environment新增默认可取消方法，旧第三方实现默认等待原exec实际完成、不虚称即时中断。

## 7. 字段变化

Todo保留原JSONL的id/title/status，新增严格结构读取而非新存储格式；原子替换同目录临时文件。审批增加可选Run/call/工具和最终输入绑定。使用完整JSON Value精确内容作为绑定而不引入新加密库，不将摘要碰撞或截断文本用于授权；仅进程内可信上下文，不是远程认证凭据。Session JSONL格式本阶段不变化。

## 9. 影响、数据流和实现

复用AgentLoop/HookChain/guardrail/ApprovalManager、ToolSpec metadata、原工具主体、Environment、sandbox进程组/Job和OS文件锁。延展调用上下文与可取消执行；新增invocation/process模块仅承担原模块缺少的输入绑定/统一进程生命周期，禁止第二套推理、注册表或解析器。

D05：原注册表把Write/destructive标记落实到requires_approval；BeforeHook只运行一次并最终确定输入，统一validate→guardrail+requires_approval→绑定审批→执行前重验。并行仅ParallelSafe可并行，PathScoped/未知metadata保守串行，NeverParallel作为批次屏障；T3再引工作区共享/独占资源协调，不能把本阶段批次调度声称跨Session锁。审批期间无工具资源锁。D06：FuturesUnordered逐个完成即发，JoinError在任务外转换并保留ID，任务内部只计执行耗时，取消不drop实际调用。D07：注册表Environment注入；批准只适用本Run/call/最终输入，bash仍执行危险判定；观察接口位于执行前重验后、进入工具主体前；失败统一为Store，收齐工具配对并终止Run，不能让模型假完成。D08：Linux管理进程组、结束时杀遗留后台子进程并wait；Windows复用挂起创建→Job分配→恢复，失败的挂起进程也回收，双管道并发排空，达到上限仍读弃。取消后等待真实退出和管道结束，spawn_blocking不代替中断。D09：任何受限策略后端不可落实即拒绝；Linux域名白名单无实施能力则拒绝，Windows现有token/环境提示不能证明网络隔离，受限组合拒绝而不降本地。D10：执行sh/cmd固定launcher并显式选择分析链；cmd无grammar保守审批，未知不能改判Safe；UNC/device命令cwd在创建前拒绝，避免cmd目录回退。D34：复用原SandboxedCommand builder；Unix参数按字面值引用，Windows无法安全字面化的参数及未实现env覆盖在执行前拒绝，不静默忽略。D11：原Todo模块公开真正只读结构查询，不mkdir/锁文件写入；写入用原OS独占锁覆盖完整读改写并原子替换，损坏/权限报错；数据根被链接重定向到授权根外则拒绝。
