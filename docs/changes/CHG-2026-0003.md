## 2. 变更原因

用户在Office确认生成报告或命令时，必须执行确认的最终输入；拒绝不产生副作用，停止后命令孙进程必须结束。当前Hook晚于审批、并行遗漏校验/metadata、bash不接受外层授权、子进程树与Windows管道、隔离降级、Todo并发均违反此需求。修复D05—D11及同一出口的D34；全量门禁新发现D35（现有TLS传递依赖安全补丁），不提前实现Office菜单/路由或Host资源协调。

T1前置已核实：用户本轮明确审核通过；GitHub PR #5已合入，T2基线ac1b58285fb6c73dce6363ce88fe62100199bb73，T1最终head 383d0922eba3d069794015e1f280668a690c482c。实际使用merge commit，不虚构squash或独立GitHub reviewer。T1 push CI通过；PR事件的另一轮CI因GitHub账单/额度未启动，历史失败保留，不称通过。T2必须重新取得当前版本双平台证据。
