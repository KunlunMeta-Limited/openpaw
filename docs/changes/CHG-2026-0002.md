## 2. 变更原因

Office需要真实模型对话、可靠停止、完整工具历史与重启恢复。当前引擎覆盖取消信号、超时未生效、发送占位模型，CLI过滤User工具结果且以压缩后数组切片计增量，Store追加损坏尾会污染后续记录。修复D01—D04及阻塞同一需求的新发现D31—D33，不实现Office路由、审批授权/进程后端T2或Host T3。

T0前置：用户本轮确认审核通过；GitHub #4已合入76e2ee2。GitHub页面无独立Review记录，不能编造审核账号。历史T0主CHG保持原PR快照，完成事实在master和本CHG同步。

## 6. API 变化

兼容run_turn，新增RunContext/RunOutcome/RunObserver；取消返回明确错误。ToolExecutor新增有默认实现的取消通知方法，旧实现等待实际call返回，不能保证立刻杀进程；T2实现托管执行。Provider装配集中在llm原模块，显式模型优先默认模型；空模型拒绝。

## 7. 字段变化

JSONL追加context_snapshot、run_started、run_finished事件，旧事件格式不变，旧读取器按Unknown兼容；不增加第二账本。快照仅替换模型上下文，原始Message事实保留。Run终态独立记录，usage来自Provider，不虚构失败流用量。
