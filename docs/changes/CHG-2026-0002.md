## 2. 变更原因

Office需要真实模型对话、可靠停止、完整工具历史与重启恢复。当前引擎覆盖取消信号、超时未生效、发送占位模型，CLI过滤User工具结果且以压缩后数组切片计增量，Store追加损坏尾会污染后续记录。修复D01—D04及阻塞同一需求的新发现D31—D33，不实现Office路由、审批授权/进程后端T2或Host T3。

T0前置：用户本轮确认审核通过；GitHub #4已合入76e2ee2。GitHub页面无独立Review记录，不能编造审核账号。历史T0主CHG保持原PR快照，完成事实在master和本CHG同步。

## 6. API 变化

兼容run_turn，新增RunContext/RunOutcome/RunObserver；取消返回明确Error::Cancelled；新增Error/SessionEvent变体时，仓库外对枚举穷举匹配的调用方需要补分支，不将旧入口签名兼容表述为所有下游源码零修改。ToolExecutor新增有默认实现的取消通知方法，旧实现等待实际call返回，不能保证立刻杀进程；T2实现托管执行。Provider装配集中在llm原模块，显式模型优先默认模型；空模型拒绝。

## 7. 字段变化

JSONL追加context_snapshot、run_started、run_finished事件，旧事件格式不变，旧读取器按Unknown兼容；不增加第二账本。快照仅替换模型上下文，原始Message事实保留。Run终态独立记录，usage来自Provider，不虚构失败流用量。

## 9. 影响、数据流和实现

复用AgentLoop、SessionEvent、SessionReader/Writer、Provider与SQLite。延展运行上下文/可等待事件和既有JSONL事件；通用修复保留原crate。新增run和assembly是缺失的协议无关装配/生命周期职责，不增加推理循环或解析器。

D01：Agent默认使用Provider真实默认模型；共享配置可指定模型和端点，CLI使用相同装配。D02：每次Run使用独立子token并保留父关系，同实例拒绝并行；独立总预算、流空闲和工具时间；所有无副作用等待可取消；工具取消通知后等待实际清理，不drop后台任务。已输出文本后不重试拼接。D03：观察接口在工具执行前持久化assistant及call ID，按发生顺序保存全部消息/usage/结果/终态；压缩保存上下文快照，不以数组长度/角色推断事实。写入失败终止，不重复工具。D04：读写共享字节扫描；仅容忍最后损坏行，append前先创建独占备份并同步，再截尾；完整但无换行的尾补分隔。中间损坏拒绝修改。
