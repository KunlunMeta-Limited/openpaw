## API、字段与数据流
- 复用现有OfficeAction `register_artifact {sessionId,workspaceId,path}`。主Agent增加同名工具，成功结果及调用写入既有session消息，Gateway从结构化工具事实重建；不增加另一套持久化协议。旧对话仅用最终正文明确提及的成功写入路径及显式文件链接兼容，去除中文交付标题要求。临时文件不会仅因write成功而上架；子空间仍独立。
- HTML父页面通过普通Origin校验的POST `/office/html-preview`（path）获得临时随机能力路径baseUrl。资源GET `/office/html-preview/:token/*`仅允许该产物目录中的白名单静态资源，复用安全路径/链接/8MiB校验，拒绝隐藏段、越界和Home，限128能力/30分钟。只该能力路由允许opaque iframe的CORS；不对其他路由允许null Origin。无持久化写入。
- HTML iframe保持sandbox=allow-scripts且无同源/导航/弹窗/表单权限。删除用户base，仅注入能力base；CSP仅额外允许对应能力路径，远程资源仍仅HTTPS。通用事件诊断仅影响UI，不篡改HTML业务结果。不可达外部资源不能被宣称已修复为在线，也不替换服务商。
- 分类按扩展名/MIME/kind，与文件名中的业务词无关。JSON/CSV可切换原始数据与地理预览，避免普通数据被强制地图接管。图表上限明确告知，保留完整原数据。
- 命名由模型给出职责描述，优先中文；不按关键词翻译，不删除中英文混合名称中的必要技术标识；逻辑key/workspaceId保持。
