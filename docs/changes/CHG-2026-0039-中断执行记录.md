## 数据与替代方案

Engine 的每回合可选 fallible recorder 同步返回 Result。实际授权后、调用工具前持久开始；实际结果持久后再发布完成。可见文本及完整工具请求保存为同 session JSONL execution_attempt_v1 Unknown，通过原 journal/writer fsync。Store 单独回放 attempt，不作为 Transcript.messages。Host/CLI 组装 callback，不持第二个 writer。工具拒绝、错误、取消和无确认结果区分；后者未知，不宣称撤销副作用、不自动重跑。原 main 历史 envelope 仍仅使用已提交消息。T07 使用这些记录做进程恢复。

拒绝 void event sink 中取消/抛 panic 代替 fallible recorder；无法保证副作用前持久化。拒绝把失败半条 ToolUse 混进模型上下文；会破坏后续模型消息结构。拒绝另建日志文件和第二个 writer；违反 ADR003。
