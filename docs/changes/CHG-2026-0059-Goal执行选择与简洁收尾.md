## 1. 问题及证据

用户要求修复“查武汉和长沙天气后弹菜单让我选择查看内容”。原会话没有任何模型 `request_user_input` 调用，仅有后端固定的计划确认菜单。模型把列出文字选项当作交付，用户未选择就完成全部验收。执行末尾还被 `GoalContext::presentation()` 追加重复任务全文、验收依据和内部观察编号，影响阅读。

已有只读诊断及反馈脚本见同目录 `diagnosis.md`、`inspect-latest.ps1`。脚本只检查已保存记录，输出计数，捕获症状时退出1；不调用模型、不改原会话。原件只证明历史故障，不将修改代码后再次检查同一历史记录声称为修复验收。

调用链另有必要接线：`session_tool_host` 当前把 Question 包在 Goal 外侧，模型直接提问不会经过 Goal 的观察记录。固定计划确认另走 `goal/review.rs`，必须继续与业务选择区分，不能用“执行计划”的回答代替“看哪个城市”。

## 2. 修复后的行为

1. 计划明确区分“收集数据”和“取得用户选择后展示”。用户要求选择时，相关任务声明 `requires_user_input=true`，验收条件包含取得实际回答并按答案交付。完整确认计划中显示该项需要用户选择。
2. 执行提示、工具参数说明及未完成续行指引明确要求调用真实 `request_user_input`；列出普通文本选项不建立待答问题。自然语言含义仍由模型在规划时解释；本变更提供结构化约束和执行校验，不宣称程序能无误理解任意措辞。
3. 已登记需选择的任务，只有实际提问工具返回可靠保存的答案后才允许 `record_result`；`accept_task` 同时核对该任务的真实回答和原有逐条件产物验收。未调用、超时、取消、存盘失败、仅有计划确认、其他任务/会话的答案均不能替代。
4. 业务回答继续作为原工具结果自动交回原 Agent，在同一回合、剩余预算中继续工作。当前请求先修复缺失菜单及可读性；不创建新用户回合、不另行 POST“用户选择”，不新增独立用户气泡。单独消息回显的表现尚未确定，不因本修复默认扩展。
5. 后端追加的最终 Goal 展示缩为简明完成/未完成计数及必要阻塞提示，正常结果仍由模型正文呈现；提示模型面向用户说明所选内容、必要来源与时间，避免输出内部观察编号。完整计划确认、原件、验收事实及详情保留，不在最终正文重复整份审计记录。
6. 普通聊天、无选择任务、原计划确认、子 Agent 协作、人工阻塞和取消沿用既有规则。首版选择任务由主 Agent 负责向用户提问和汇总，子 Agent 仍可承担数据收集；其内部问题不得冒充主任务的选择答案。

## 4. 字段、信任与兼容

- `goal_update.tasks[].requires_user_input` 是可选布尔计划字段，持久私有 GoalTask 默认 false，以兼容旧日志；工具 schema 和提示要求新生成计划明确判断。它不是回答、进度或执行授权。模型不能提供问题已回答标记或伪造可信答案。
- 问题仍使用现有 `request_user_input`、`UserQuestionRecord` 和 `user_question_v1`。Goal 仅观察真实工具成功返回的 `question_id`、scope、answer，并绑定当前所选任务、发起回合及计划；原 Question 层已经校验身份、截止时间和可靠提交。失败外层返回不能记成有效回答。
- 固定计划审核不经过业务提问观察，且不存在当前执行任务归属；不得满足 `requires_user_input`。业务回答不批准重规划、不改变工具权限。
- 重规划不能清掉尚未满足的用户选择要求：同身份不得降为 false；替换/拆分须有保留要求的当前后继；直接移除未满足要求应拒绝并要求原聊天明确编辑。已暂停后用户确实修改需求时，沿现有真实 `user_excerpt` 编辑路径处理。任务定义变更不能沿用其旧 accepted 状态。
- 对已保存回答的复核须维持其真实任务/定义/来源，压缩或重启不会创建新答案；旧版本无关答案不可借用。重启不自动执行，仍须用户明确继续；同任务有效答案避免无理由重问。
- 沿既有逐条件验收检查选择后的实际产物，成功提问本身不证明天气正确或所选内容已交付。记录“已经列出选项”不满足本次选择任务。
- 不修改 Core/Engine/Store 的公共类型、trait、持久消息协议、HTTP/SSE/Office 字段、路由、Cargo 或依赖。JSONL 仍只通过 runtime/Store 唯一 writer 追加，不改写历史。

6. 最终聊天不被后端重复附加任务全文、验收条件或 obs 编号；必要简短状态与阻塞原因可见，完整确认计划和记录仍可核对。
