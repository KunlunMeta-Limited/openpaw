## 禁止路径与替代方案

不修改 Core/AgentLoop 公共 trait、Cargo 依赖、CI 或存储格式；这些不是本次兼容修复的位置。不为减少行数删除功能或测试，不把协议类型迁到 Core。不修改 Office 角色终态，不实现可靠动画 v2。保留现有根路径去重与统一全局 SSE。替代的前端 time 容错不能修复 Host 不一致契约，因此使用服务端共享投影。

## 数据流与部署

OpenWork browser → OpenWork server → 唯一 engine-host；AI Office browser → Gateway → 同一 engine-host。Host 独占 sessions 写入；Gateway 对 sessions/skills 只读、goals 独立可写。两端共享容器目录 `/workspace`。容器监听 0.0.0.0 作为已批准部署例外，宿主仅回环发布；Host 全路由 Basic Auth。DeepSeek key 仅传给 Host，日志和报告禁止包含凭据。
