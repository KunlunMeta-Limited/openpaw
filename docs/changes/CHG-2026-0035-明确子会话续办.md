## 接口、方案与替代

delegate_task 保留 task/name，新增可选字符串 task_id；它必须是真实子 Session ID，旧 feature workspaceId 只保留展示用途。缺少 ID 新建，即使同名同文字也真实执行；明确 ID 只恢复自己的已提交历史。不存在、非子、跨父、跨目录、归档、删除或忙碌均明确拒绝且不新建替代。父可见工具文本/structured 返回真实 ID；系统上下文从会话目录只读列出本父可续用身份。结果只取本次回合新消息，不回传上一轮答案。沿用已有 HTTP requestID 去重，不新增按文字缓存。

不采用复制父上下文、名字匹配或新持久化数据库。保持本轮前台委派及单主对话约束；持久授权寿命与停止的完整矩阵由 T05 收口，T02 不扩大授权。新子及续办均通过统一 accept_turn/run_turn/Store writer。
