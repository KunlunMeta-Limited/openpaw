## 行为与授权

Host 每次启动的首次成功 offices.initialize 指定 layoutId="members"，即使网关已有就绪目录且未配置聊天地址也要完成首次初始化。
请求失败保留首次标志，下一周期重试；网关接受200/202后不再携带布局，后续办公室分片、目录重同步和新增办公室不覆盖用户手动布局选择。
沿用当前15180服务的部署授权，仅更新对应Host，前端不修改、不重建；不发送真实模型请求或续跑Goal。

## 实现与替代方案

首次登记标志改为首次成功初始化标志，ready不能跳过本次Host初次初始化；首个被接受的分片后立即置位。
不在每次同步传members，避免反复覆盖手动选择；不在前端改默认值，不新增配置或持久格式。
Host当前13496/13500；只做必要变更，保持上限与计数算法，不搬移其他职责规避门禁。
