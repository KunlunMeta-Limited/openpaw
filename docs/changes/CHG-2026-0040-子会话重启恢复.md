## 接口和数据

既有 HTTP/事件枚举不变。execution_attempt_v1 原格式追加 disposition=unknown 的 tool_result；已有结果不覆盖，第二次恢复不重复。session_child_v1 增加可选 parent_message_id（旧记录缺省时只保留已有历史关系）；这是身份来源而非权限。MainOffice 内部弱 runtime 只用于已验证办公室员工的现有 get_typed 懒加载。旧 display ID 不冒充合法 Session，展示真实旧任务/可证实结果及“完整历史未保存”，不提供 task_id 续办。

## 实现与替代

Store 仍负责回放，Host 负责启动策略，原 writer 串行追加；不另建日志、双 writer 或恢复旧授权。来源按父可见输入核验，Fork 根不复制 child 关系，Revert 隐藏来源后不再续用。拒绝清空损坏会话、自动补跑工具、缓存答案伪装会话及启动全量重放动作。

## 测试与回退

既有批准 seam：Host 公共 HTTP/SSE → 真实 Engine/Store → 受控外部 Provider/临时文件。逐项 RED→GREEN；至少一项真实 kill 进程。检查已存结果不变、无结果 unknown 一次、完整前缀及损坏中段 fail-closed、查看不执行、冷员工四视图、同 ID 明确续办、旧记录缺失声明、归档/delete/Fork/Revert 不复制权限。受影响 Host/CLI parity、严格 Clippy/fmt 与 diff 全量复验；行预算不调整。

回退前停止 Host，备份完整 home 和 workspace；不删 Unknown/旧快照/工作产物。旧 reader 可忽略新事实因此不能承诺展示新记录；已写 session_revert_committed_v1 的日志只回退到认识该事件的 reader。保存旧文件逐字节及生成产物证据，无破坏式下迁移。
