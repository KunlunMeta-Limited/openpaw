## 行为、方案与替代

同一 child 的 gate 原子拒绝第二活动回合，不同 child 复用父调度授权并共享模型信号量。仅可信父子关系能继承调度额度，权限不继承。真实 child 上的 always 请求只批准该次调用；根原有 always 保持。保留原 HTTP 字段、权限 ID 和错误码。父停止、断连或原超时后取消其本轮子执行，等待已登记子 run_turn 完成持久终态，不以 Office 状态清理冒充执行收尾。不增加第二个 AgentLoop/日志/调度器。

不采用直接丢弃子 future、复用父审批管理器或关闭并发上限。只读详情、容量、重启迁移不在本票扩张；原页面审批证据由集成候选补充。

## 验证与回滚

逐行为公开 Router RED → GREEN，受控外部模型、同步栅栏、真实工具和临时 home/workspace。记录单子竞争、独立子并行、额度恢复、单次允许/拒绝、重复迟到批准、父取消和其他父继续的实际响应及会话终态。随后 Host lib/HTTP/reliability、fmt、Host 严格 Clippy。全工作区门禁由集成统一运行，不将受控模型当真实模型验收。回滚前停止运行并备份 OPENPAW_HOME；保留全部子历史及工具产物，不自动补跑。

## 实际结果

2026-10-21：已实现父前台子任务所有权。子接收和任务登记与父收尾关闭登记共用短锁；接收后不跨 await 就登记实际 run_turn，避免父取消丢弃工具 future 后子一直停留 running。父收尾取消仍活动的确切子回合并等待任务持久终态后才提交父终态，不误伤已换回合的子身份。原会话、写入事务、模型限额和工作区锁均复用。真实 child 的所有 reply 路径即使收到 always 也只批准单次；根会话原 always 不改变。

证据位于 office2/artifacts/subagent-design/t05。RED red-cancel-terminal：main 响应断连后父已 idle，子公开 turns 仍 running，exit 101。GREEN green-cancel-terminal：子 cancelled 和 completedAt 在父终态发布前保存，exit 0。RED red-child-always：批准首个 child write_file 为 always 后第二个调用未再请求卡片，公开等待超时，exit 101。GREEN green-child-always：同轮第二调用和公开子会话下一轮重新审批，拒绝无副作用，旧 ID 重复回复均 404，exit 0。最终测试继续覆盖显式 task_id 再委派，不将旧授权带入新委派。

concurrency-locks：父全局容量 1、模型容量 2 时不同子同时抵达 bash；真实独占目录断言与开始/结束序列证明共享工作区写锁只允许一项进入，不发生碰撞。同一 task_id 的两次并发只产生一个新回合；公开第二次提交 409，父工具历史记录明确忙碌，最终额度/状态清空，exit 0。parent-stop-isolation：两个父各有实际子模型等待，停止一个父后自己的子保存 cancelled，另一个父子仍 busy，释放受控模型后另一个正常完成，停止的父也能再次执行，exit 0。

original-180s-deadline：未缩短原版 180 秒期限，子实际执行 300 秒 sleep 工具；180 秒 main 原计时器取消，子先持久保存 cancelled，16ms 后父保存 cancelled，全部 idle，exit 0。该慢测试标记单独集成运行，已真实运行；后续还以 --include-ignored 纳入本票最终 Host 全量。中间编译错误、命令安全链拒绝复杂 shell 的探索均保留日志，修正为真实 python 测试脚本执行，不作为产品失败或验收证据。
