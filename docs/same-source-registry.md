## Rules

1. A same-source artifact is never hand-edited on the upstream side once it
   lands here; upstream consumes by reference (subtree / git dep).
2. Any change to S1–S7 must update this registry in the same PR and pass
   the golden bidirectional tests (Q6) on both sides.
