## 1. 验收原则

需求必须落到可观察的请求、状态码、事件顺序、JSONL、Office envelope、退出码或资源指标。
状态只允许：`已编码`、`局部验证`、`失败`、`阻断`、`待实施`、`范围外`。
历史绿测、mock、skip 或测试源码存在不能替代当前候选验收。

## 4. 发布和回滚

- 人工批准 CHG-2026-0013、CHG-2026-0014、CHG-2026-0015 后才能修改其登记源码。
- JSONL、HTTP/SSE、动画 v2 Schema 或 Cargo 变化必须按 CHG 文件范围实施；新增范围必须重新审批。
- 关闭和回滚不得删除 session、outbox 或 journal；先停止接收，再取消/等待，最后验证旧数据可读。
- 写入 `session_revert_committed_v1` 后只能回滚到仍识别该事件的兼容 Host；不得部署会重新显示
  已逻辑删除尾部的旧 reader，也不得通过重写 JSONL 规避此限制。
- T10 第 5 号角色保持整理还是全部 idle，以及 cancelled 是否触发整理，必须由根计划负责人决策。
- OpenWork T7/T9/M4 与完整 T13/M6 不在本仓可独立关闭的范围内。
