## 5. 当前接口和数据流盘点

### Host 对外接口

已从 `crates/openpaw-engine-host/src/http.rs` 识别：`/global/health`、`/session`、
`/session/:id`、`/session/:id/message`、`/session/:id/prompt_async`、`/session/:id/abort`、
`/session/status`、`/event`、`/global/event`、`/api/event`、`/provider`、`/permission`、
`/permission/:id/reply`，以及 `/config`、`/mcp`、`/command`、`/project`、`/agent`、
`/find/file`、`/shell`、`/fork`、`/revert`、`/summarize` 的降级/占位路由。

这些路由已在 `项目设计基线.md` 分配 API 编号。未知 v2 路径应保持 404；新增路由必须先更新设计、
Schema、CHG 和测试，不能只在 `Router` 中添加一行。

### 数据流和写入点

```text
HTTP prompt -> http.rs 校验 -> runtime.rs 保留 session
  -> AgentLoop -> events.rs SSE/message -> runtime.rs 追加 sessions/*.jsonl
  -> office.rs 异步 POST Office Gateway（失败隔离）
```

唯一持久化写入点是 Host runtime 的 session JSONL；审批 pending 属于内存状态；Office 动作只向
外部 Gateway 投影。`openpaw-core`、OpenWork 和前端不应被 Host 为 B 线方便而直接改写。
