# OpenPaw B 线项目设计基线

版本：`DES-OPENPAW-B-2026-09-15`（首次反向接入草案）
状态：待确认。本文根据当前源码、`master-plan.md` 和 `docs/b-line/` 反向整理，不能替代架构负责人批准。

## 1. 目的、范围和事实来源

本基线约束 OpenPaw 在 B 线中承担的 engine-host 行为，并约束它与 AI Office Gateway 的跨仓库边界。
OpenWork 的 A 线协议是 Host 的兼容消费者，但不属于本次 Office UI 实现范围。

事实来源按优先级排列：

1. 人工批准后的本基线和对应 CHG；
2. `D:/Workspace_bak/master-plan.md` 的 B 线章节；
3. `docs/b-line/protocol.md`、`data-flow.md`、`architecture.md`、`testing.md`、`traceability.md`；
4. 当前源码和测试；
5. 未登记的自然语言约定只能标记为“待确认”，不能作为 AI 编码依据。

## 2. 架构分层和依赖方向

```text
openpaw-cli（启动入口、feature 开关）
        -> openpaw-engine-host（HTTP/SSE/协议/审批/Office 投影）
        -> openpaw-engine（AgentLoop、AgentEvent、取消）
        -> openpaw-core / openpaw-llm / openpaw-tools / openpaw-store
        -> 文件系统和外部模型服务
```

Host 是适配层，不得把 OpenCode 或 Office 专用类型移入 `openpaw-core`。Host 的写入权如下：

| 数据或状态 | 唯一写入者 | 读取者 | 约束 |
| --- | --- | --- | --- |
| session JSONL | `runtime.rs` 的 session writer | Host message/status、Office Gateway | 追加写；不允许 UI 直接写文件 |
| AgentLoop 回合状态 | `runtime.rs` | HTTP status、SSE、Office 投影 | 同一 session 只能一个活动回合 |
| permission pending | Engine approval gate；Host approval.rs 做协议 adapter | permission GET/reply、SSE | reply 或 abort 后必须清理 |
| OpenCode SSE | `events.rs` + broadcast | OpenWork/测试客户端 | 只发送协议登记的事件和顺序 |
| Office action | `office.rs` 单发送队列 | AI Office Gateway | POST 失败/超时不得改变回合结果 |

允许内部实现变化：私有函数、队列实现、缓存和不改变契约的性能优化。必须冻结：公共协议字段、
路由、错误码、状态机、依赖方向、feature 隔离、权限和取消语义。

## 4. Host HTTP API 目录（已实现反向登记）

接口编号稳定，不随函数重命名或文件移动改变。所有响应错误均为 JSON，除特别说明外不写入状态。

| 接口编号 | 方法和路径 | 中文名称 | 成功结果 | 失败/边界 |
| --- | --- | --- | --- | --- |
| API-HOST-HEALTH-001 | `GET /global/health` | 查询 Host 健康状态 | `{healthy:true}` | 回环服务不可达 |
| API-HOST-SESSION-001 | `POST /session` | 创建会话 | 返回 session 对象并发送 created | JSON 错误 400 |
| API-HOST-SESSION-002 | `GET /session` | 列出会话 | session 数组 | 目录不存在按空数组处理 |
| API-HOST-SESSION-003 | `GET /session/:id` | 查询会话 | 单个 session | 不存在 404 |
| API-HOST-SESSION-004 | `GET /session/:id/message` | 查询会话消息 | message 数组 | 不存在 404 |
| API-HOST-SESSION-005 | `GET /session/status` | 查询活动状态 | `{id:{type}}` 或 `{}` | 只读当前内存状态 |
| API-HOST-SESSION-006 | `POST /session/:id/prompt_async` | 异步提交回合 | 204；回合后台执行 | 同回合 409；会话 404；解析/Provider 400 |
| API-HOST-SESSION-007 | `POST /session/:id/abort` | 取消回合 | `true` | 会话 404；取消后最终 idle |
| API-HOST-SESSION-UPDATE-001 | `PATCH /session/:id` | 更新会话 | 原子更新 title 和/或 `time.archived`，返回 Session | 空 patch、空标题、负归档时间 400；不存在 404；活动归档 409 |
| API-HOST-SESSION-FORK-001 | `POST /session/:id/fork` | 创建会话分支 | 返回具有新 ID 的根 Session；可选 `messageID` 严格排除边界及尾部 | 边界非法 400；不存在 404；活动会话 409 |
| API-HOST-SESSION-REVERT-001 | `POST /session/:id/revert` | 暂存会话回退 | 隐藏 `messageID` 及尾部并返回带 `revert` 的 Session | `partID` 返回 400 `unsupported_part_revert`；不存在 404；活动会话 409 |
| API-HOST-SESSION-UNREVERT-001 | `POST /session/:id/unrevert` | 取消暂存回退 | 恢复暂存尾部；无暂存时幂等返回当前 Session | 不存在 404 |
| API-HOST-SSE-001 | `GET /event` | 订阅会话事件 | SSE data 帧 | 仅收连接后的事件 |
| API-HOST-SSE-002 | `GET /global/event`、`GET /api/event` | 订阅全局事件 | SSE data 帧 | 其他 GET 不得返回 SSE |
| API-HOST-PROVIDER-001 | `GET /provider` | 列出 provider | all 四项；connected 按本地配置可用性筛选；default 保留显式值 | 未支持 provider 400 |
| API-HOST-PERMISSION-001 | `GET /permission` | 列出待审批 | permission 数组 | 只返回当前 pending |
| API-HOST-PERMISSION-002 | `POST /permission/:id/reply` | 回复审批 | 204 并发送 replied | id 不存在 404；reply 非法 400 |
| API-HOST-DOWNGRADE-001 | `GET /config`、`GET /mcp` | 查询未实现配置能力 | `{}` | 明确降级，不假装完整实现 |
| API-HOST-DOWNGRADE-002 | `GET /command`、`/project`、`/agent`、`/find/file` | 查询未实现列表能力 | `[]` | 为兼容 SDK，不能改成 404 |
| API-HOST-DOWNGRADE-003 | `POST /session/:id/command`、`/session/:id/shell`、`/session/:id/summarize` | 未实现写操作占位 | 204 | OpenCode v2 和未登记路径 404 |

## 5. 事件、字段和状态约束

| 事件编号 | 事件 | 必要字段和顺序 |
| --- | --- | --- |
| EVT-HOST-SESSION-001 | `session.created` / `session.updated` | `properties={sessionID,info}`；`info` 为完整 Session；创建、标题、归档、回退状态变化时发送 |
| EVT-HOST-SESSION-002 | `session.status` | `sessionID` + `status.type`；回合开始 busy、结束 idle |
| EVT-HOST-SESSION-003 | `session.idle` | `sessionID`；回合结束最后发送 |
| EVT-HOST-MESSAGE-001 | `message.updated` | info.id/sessionID/role/time；user 在 prompt 后，assistant 在输出开始 |
| EVT-HOST-MESSAGE-002 | `message.part.updated` | text/reasoning/tool part 完整声明后发送 |
| EVT-HOST-MESSAGE-003 | `message.part.delta` | partID/sessionID/messageID/field/delta；只能追加对应 part |
| EVT-HOST-TOOL-001 | tool part 状态 | running -> completed/error；`callID` 使用 tool_use_id |
| EVT-HOST-PERMISSION-001 | `permission.asked` | permission 对象；manual 等待 reply |
| EVT-HOST-PERMISSION-002 | `permission.replied` | sessionID/requestID；reply 后 pending 必须删除 |

公共字段采用原始线协议名 + 中文解释：`sessionID`（会话唯一编号）、`callID`（工具调用编号）、
`type`（状态/动作枚举）、`time.created/completed`（Unix 毫秒）。协议类型的中文 Rustdoc 必须引用
对应接口编号，详细注释格式见框架 `docs/注释规范与示例.md`。

## 6. 数据流、状态机和失败语义

```text
HTTP prompt
  -> http.rs 校验 body、provider 和 session
  -> runtime.rs 原子保留 session 回合
  -> AgentLoop 产生 AgentEvent
  -> events.rs 转 OpenCode SSE / message
  -> runtime.rs 追加 JSONL
  -> office.rs 异步投影动作（失败只记日志）
```

- user 文本按输入 part 顺序拼接，不插入额外分隔符；非 text part 忽略。
- 回合状态为 `idle -> busy -> idle`；同一 session busy 时新 prompt 返回 409，不同 session 可并行。
- abort 必须传播到 AgentLoop、审批等待和延迟 stream；abort 后不再发新的 text delta。
- `permission.asked -> reply -> permission.replied` 是完整审批链；abort 时不发送迟到的 replied，
  但必须清除 pending。
- JSONL 追加是唯一会话持久化路径；Office Gateway 只读这些文件，不得由 Host 直接改变 Office 数据。
- `session_metadata_v1`、`session_fork_origin_v1` 和 `session_revert_*_v1` 只追加、不物理重写历史；
  staged revert 仅隐藏尾部，下一条被接收的 prompt 通过复合记录提交逻辑裁剪，此后不能 unrevert。
- Branch 是独立根会话，不返回 `parentID`；来源只保存在 Host 私有事件。直接分支标题按
  `Title (1)`、`Title (2)` 递增，分支的分支在当前标题后继续追加序号。
- 写入 committed revert 后，不得直接降级到无法解释 `session_revert_committed_v1` 的旧 Host，
  否则旧 reader 会重新暴露逻辑删除的尾部。
- Office POST 超时上限 500 ms、无重试；网络失败不能取消回合或改变 AgentLoop 结果。

## 7. 保护等级和禁止方向

| 等级 | 当前路径 | 规则 |
| --- | --- | --- |
| L4 | `crates/openpaw-core/src/**`、`crates/openpaw-engine/src/agent_loop.rs` | 必须架构、安全、兼容和回滚审查；未经 CHG 不得修改 |
| L3 | Host `protocol.rs/http.rs/events.rs/runtime.rs/approval.rs/office.rs` | 必须接口 CHG、契约测试和 CODEOWNER |
| L3 | `Cargo.toml`、`Cargo.lock`、Host/CLI Cargo.toml | 必须说明依赖、feature 和默认树影响 |
| L3 | `.github/workflows/**`、`.github/CODEOWNERS` | 必须说明合并门禁和责任人变化 |

禁止：把 Host/Office 类型移入 Core；新增未编号路由；绕过 runtime 写 session；将敏感内容写入
SSE/Office/log；用 Office 请求失败改变回合；把 `axum` 放入默认 feature；在未批准 CHG 中顺手重构。
