# 中文注释规范与示例

新增或行为变化的公共/跨模块Rust声明用中文Rustdoc，不在未触及文件上强制清历史债。函数/方法八栏目：功能、参数、返回、错误、状态、并发与取消、权限、关联；不适用写“无”，不能省略或填空泛占位。关联优先稳定REQ/DES/契约，D/CHG集中追踪，不把全部历史编号铺到源码。

~~~rust
/// 功能：读取已保存的会话摘要。
/// 参数：id为调用方已授权的会话标识。
/// 返回：当前摘要；不存在时返回空选项。
/// 错误：存储损坏或权限失败时返回诊断。
/// 状态：无。
/// 并发与取消：共享读取，不持有运行锁。
/// 权限：调用前必须校验会话归属。
/// 关联：REQ-OP-004；DES-OP-003。
~~~

类型/枚举/字段/关联常量：用途、字段（或变体）、来源去向、约束、稳定性、关联。模块：职责、输入输出、依赖、禁止职责。重导出沿用定义说明，宏生成公共声明人工核对，不能声称静态检查能展开任意宏。

复杂实现说明为何如此、取消/锁/持久化边界、不变量和失败恢复；不逐行翻译代码。unsafe保留SAFETY并解释中文安全理由，core原Stability标记不能删除。协议标识和第三方原文保留原样。

xtask comments复用syn、quote与既有doc_lines；比较base/head的语法节点，只阻断新增、实现变化或注释变化的公共/跨模块声明，覆盖pub(crate)、trait方法、public字段、impl方法和嵌套模块。未变公共声明不因同文件私有编辑被强制补全。全量report用于看历史缺口，不作为增量通过替代。

AST检查只能证明有对应栏目/中文，不能证明描述正确；关联含义、宏生成API、平台权限等继续人工审核。新代码/八栏目/历史增量均有正反测试。
