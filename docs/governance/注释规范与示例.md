## 公共类型或字段

```rust
/// 功能：表示 OpenCode v1 子集中的会话状态。
/// 字段/变体语义：`busy` 表示存在活动回合；`idle` 表示没有活动回合。
/// 数据来源：`runtime.rs` 的 session 保留状态。
/// 数据去向：`GET /session/status` 和 `EVT-HOST-SESSION-002`。
/// 约束：同一 session 只能有一个 busy 回合。
/// 稳定性：跨项目公共契约，修改必须建立 CHG 和 Schema diff。
/// 关联：`API-HOST-SESSION-005`。
pub enum SessionStatus {
    Busy,
    Idle,
}
```

模块使用 `//!` 说明职责、输入输出边界、禁止承担的职责和关联设计章节；复杂内部逻辑使用 `//` 说明不变量、边界和失败原则。不要求给每一行代码写解释性注释。
